# Residence Vision

A modern web application built with [Next.js](https://nextjs.org) for residence management and visualization.

## Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm package manager

### Installation

1. Clone the repository:

```bash
git clone https://github.com/gabrielsdi/residence-vision
cd residence-vision
```

2. Install dependencies:

```bash
npm install
```

### Running the Development Server

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Running Unit Tests

Run the test suite:

```bash
npm test
```

Run tests with a UI interface:

```bash
npm run test:ui
```
